# 既存図面から読み取った作図規則（PDF サンプル）

出典: VRAIN Solution Inc. 制御盤図面（管理番号 `A014457HSE--`）の PDF サンプル。
DXF/DWG が入手できなかったため、**PDF の見た目から読み取れた範囲**をまとめています。
数値は画面キャプチャからの読み取りなので、実装前に原図で確認してください。

## 1. 確定できたこと

| 項目 | 内容 | DXF 出力への影響 |
| --- | --- | --- |
| **使用キャビネット** | 日東工業 **ステンレス SR形 制御盤キャビネット（IP54）** | 盤マスタに SR形シリーズを入れる。ステンレス／屋外向けなので塗装品とは寸法系列が別 |
| **投影法** | **三角法**（注記に明記） | 出力する図の配置順を三角法に合わせる |
| **尺度** | **1:8** | モデル空間 1:1 作図 → レイアウトで 1:8 出図なのか、直接縮尺作図なのかは**要確認**（第3章） |
| **図面の種類** | `制御盤外観図`（A001）と `制御盤内観図`（A002）の2枚構成 | 本ツールが生成するのは**内観図の中板**。外観図は既存フローのまま |
| **取付板の呼称** | **中板**（図面上の表記が `(中板)`） | UI・図面注記の用語を「基板」から**「中板」**に統一する |
| **展開している図** | 中板 / 正面 / 左側面 / 右側面 / 上面 / 底面（外観図は背面も） | 内観図は中板＋各面。v1 が出すのは中板のみ |

### 図枠（表題欄）の項目

出力 DXF に同じ表題欄を持たせるため、読み取れた項目を控えます。

- 改訂欄: 記号（A / B / C）・`改訂内容`・`Qty`・日付
- 図面名（`制御盤外観図` / `制御盤内観図`）
- 尺度（`1:8`）
- `作成日`
- `製図` / `検図` / `承認`
- 会社名（`VRAIN Solution Inc.`）
- `管理番号`（例 `A014457HSE--`）
- `頁`（`A001` / `A002` / `002`）

### 注記の定型文

```
注記
1.本図は、三角法とする。
2.日東工業のステンレスSR形制御盤キャビネット(IP54)を使用
```

内観図を生成するときは、この2行をそのまま出せるようにします（キャビネット名は盤マスタから差し込み）。

### 仕様指定欄（外観図側）

- 仕上げ: `指定色( )` / `鏡面` / `ヘアライン`
- 取付方向: `標準(読上げ)` / `その他(図示)`
- 電源接続方法: `当社標準` / `御社指定方法`、`主幹用遮断器一次側へ引き込み(端子台)`

これらは本ツールの生成対象ではありませんが、**BOM やカバーシートに転記する項目**として設定に持たせる価値があります。

## 2. 設計に効いた発見

### 2-1. 扉面機器は実際に使っている

正面図に**表示器（タッチパネル）と複数の操作スイッチ・表示灯**、底面図に**多数のケーブルグランド／コネクタ**が並んでいます。
v1 のスコープ（中板のみ）は最短で形にするうえでは妥当ですが、**実案件をカバーするには扉面が要る**ことが確認できました。Phase 2 の優先度を上げます。

### 2-2. 熱対策が標準装備

上面と右側面に**換気ファン／ルーバー**が付いています。IP54 のステンレス盤で密閉度が高いぶん、盤内温度上昇はもともと課題のはずです。
「盤内総発熱 → 換気扇・クーラーの要否」の機能は、後回しの飾りではなく**実需のある機能**と判断できます。

### 2-3. 底面の穴加工が細かい

底面図にケーブルグランド用の穴が `4-φ21` `4-φ25穴` `2-φ22穴` といった指定でピッチ付きで並んでいます。
**加工穴座標の出力**（Phase 3 に置いていた項目）は、中板だけでなく**底面・側面も対象**になります。日東工業キャビスタの加工指定にも繋がる部分です。

### 2-4. 中板の実レイアウト

内観図の中板を見る限り、**上部に横一列（端子台または遮断器の列）、その下に機器のブロック、最下部にもう一列**という構成でした。
現在の実装（横ダクト段組み・上段から順に詰める）の方向性と矛盾しません。ただし**段ごとに高さが違う**ように見えるため、
`docs/01-spec-review.md` に挙げた **段ごとの可変高さ割り付け**が、やはり Phase 1 の最優先課題です。

## 3. PDF からは取れなかったもの（引き続き必要）

DXF 出力の品質に直結するのに、PDF からは原理的に取得できない情報です。
**AutoCAD LT の画面キャプチャで十分**なので、以下をいただけると精度が上がります。

| 欲しいもの | 取り方 | 何に使うか |
| --- | --- | --- |
| **レイヤ一覧** | LT で図面を開き `LAYER` コマンド →「レイヤプロパティ管理」のスクリーンショット | 出力 DXF のレイヤ名・色・線種を既存図面に合わせる。**これが一番効きます** |
| **文字スタイル** | `STYLE` コマンドのダイアログ | 表題欄・機器名の文字が既存と揃う |
| **寸法スタイル** | `DIMSTYLE` コマンドのダイアログ | 寸法を出す段階で必要 |
| **作図尺度の運用** | モデル空間は 1:1 か、それとも 1:8 で作図しているか | 出力座標の倍率が変わる。**間違えると全部ずれます** |
| **図枠の DWG または DXF** | 既存の図枠ファイルがあればそれ | 表題欄を作り直さずに済む |

### 尺度について補足

もし「モデル空間 1:1 → レイアウトで 1:8 出図」なら、本ツールは**実寸 mm でそのまま DXF を吐けば済みます**（一番素直）。
逆に「モデル空間に 1:8 で縮小作図」している場合は、出力時に 1/8 を掛ける必要があります。
どちらかで実装が変わるため、ここだけは先に確認させてください。
