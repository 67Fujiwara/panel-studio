# 制御盤自動配列Webアプリ プロジェクト概要（Claude Code 引き継ぎ用）

## 背景・目的

- ユーザーはAutoCADで制御盤の作図を行っており、作図自動化に取り組んでいる。
- 一番時間がかかっているのは盤内レイアウト（機器配置）作業。
- 対象案件「Vrain Solution」の制御盤は使用機器がある程度共通しているため、「使用機器の選択」と「盤サイズの選択」だけで、座標を手入力せずに自動配列できないか検討している。
- 最終的にはBOM（部品表）の自動生成、およびERPへの読み込みまで自動化したい。

## これまでの方針転換の経緯

- 当初はExcel + VBA（VBAエディタに.basをインポート済み）でAutoCADをCOM連携する方針だった。
- ただしユーザーはExcelでの作業自体が個人的に好きではないため、方針転換。
- 最終決定：**Excelを「作業台」として使わず、Python + ローカルWebアプリで統一する。**
  - AutoCADはWindowsのデスクトップアプリのため、クラウドWebアプリからの直接操作は不可。
  - 構成は「ローカルWebアプリ」＝ブラウザで入力UI（機器選択・盤サイズ入力など）を表示し、同一PC上のローカルサーバー（Python）がAutoCADをCOM経由（pywin32）で操作する形。
  - Excelは完全排除ではなく、**BOMの最終出力フォーマットとしてのみ**使う（openpyxl等で自動生成、人がExcelを触って編集する運用にはしない）。

## 推奨アーキテクチャ

- **機器マスタ（単一の情報源）**：SQLite または JSON/CSV。型式・寸法（幅・高さ・奥行き）・取付ピッチ・取付タイプ（DINレール／面実装／ドア面実装）・発熱の有無などを保持。
  - このマスタを「盤面レイアウト自動配置」と「BOM自動生成」の両方が参照する。Excelシートを分けて持つと同期崩れ（レイアウト修正がBOMに反映されない等）が起きやすいため、共通データソース化が重要。
- **配置ロジック**：ルールベース＋グリッド配置（2Dビンパッキング＋工学的制約）。
  - 例：ブレーカ類は上段に幅ピッチで左詰め配置／端子台は下段／配線ダクト幅を固定確保／発熱機器同士は離隔距離を自動確保／収まらない場合は次の段に折り返す、等。
  - 完全ゼロタッチを最初から狙わず、「自動仮配置＋人が微調整」を第一段階のゴールとする。
  - 進め方：まず1カテゴリ（例：端子台の横並びだけ）でロジックを作り、既存図面と照合して精度検証 → 他カテゴリへ拡張、という段階的アプローチ。
- **AutoCAD連携**：Python + pywin32でCOMオートメーション（VBAで書く内容をPythonに置き換える）。
- **UI**：ローカルWebアプリ（Flask/FastAPIなどのローカルサーバー＋ブラウザUI）。機器選択・盤サイズ入力を行う。
- **BOM出力**：
  - 人が確認する用：Excel（.xlsx、openpyxlで自動生成、指定テンプレートがあれば流し込み）
  - ERP取込用：CSV（機械的な一括取込に最も汎用性が高い）
    - 文字コード注意：国内ERPはShift-JIS（CP932）指定のことが多い。UTF-8だと文字化けする可能性があるためERP側の取込仕様を要確認。
    - 型式・品番のゼロ落ちや指数表記化を防ぐため、確認用Excelとは別ファイルとして運用し、CSVを人が直接Excelで開いて編集しない運用にする。
    - ERP製品名（SAP／OBIC7／mcframe／弥生など）が判明次第、取込フォーマット仕様を具体化する。

## 部品データについて

- 日東工業（Nitto Kogyo）の機器を使用予定。
- PDF図面から抽出できるもの：外形寸法・取付穴ピッチ・質量・消費電力などの仕様表 → 機器マスタのデータ化に使用。
- PDFから直接使えないもの：AutoCADに配置する実際のブロック図形（シンボル）。PDFのベクター線からの自動ブロック化は精度・手間の面で非推奨。
- 日東工業サイトでDXF/DWGのCADデータがダウンロードできる機種があれば、そちらを優先してブロックライブラリに使う。PDFしかない機種は簡易ブロック（外形＋取付穴程度）を別途作成する。

## 実装方針（Claude Codeでの実装時の前提）

- 実装環境：Python（pywin32でAutoCAD COM連携）
- UI：ローカルWebアプリ（Excelは使わない。BOM出力形式としてのみExcelを使用）
- データ：機器マスタを単一の情報源とし、レイアウト自動配置とBOM自動生成の両方がそこを参照する設計にする
- BOM出力は「人の確認用（Excel）」と「ERP取込用（CSV）」を分けて生成する
